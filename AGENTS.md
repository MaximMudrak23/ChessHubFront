
# ChessHub Frontend

## Проєкт
ChessHub — вебзастосунок для гри в шахи.
Цей репозиторій відповідає за клієнтську частину.

## Технології
- React
- TypeScript
- Vite
- SCSS
- Zustand
- Socket.IO Client

## Архітектура
- Спочатку досліджуй наявну структуру.
- Дотримуйся існуючих патернів і домовленостей.
- Повторно використовуй наявні компоненти та хуки.
- Не створюй дублікати існуючої логіки.
- Не змінюй API-контракти без узгодження.
- Не перенось серверну бізнес-логіку на клієнт.

## Розробка
- Використовуй TypeScript.
- Дотримуйся існуючого стилю компонентів.
- Враховуй адаптивність інтерфейсу.
- Для складних змін спочатку запропонуй план.
- Не змінюй backend без окремого завдання.

## Перевірка
- Визнач доступні команди з package.json.
- Запускай відповідні перевірки після змін.
- Перевіряй можливі помилки типізації.
- Повідомляй про неперевірені сценарії.
